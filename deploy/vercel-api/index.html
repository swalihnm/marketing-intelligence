Marketing Mix Modelling — trimmed API

A reduced-dependency (numpy + scipy only) deployment of the budget allocator, response curves, and experiment power calculator from a larger marketing-mix-modelling project — serving a pre-fitted Bayesian MMM posterior (300 draws, 4 simulated channels) rather than fitting live. Full PyMC model fitting, the customer economics layer, and the causal identification analysis are not in this deployment — they run locally in the full project.

GET /api/health

curl https://this-deployment.vercel.app/api/health

POST /api/allocate

Optimize budget allocation over the posterior.

curl -X POST https://this-deployment.vercel.app/api/allocate \
  -H "Content-Type: application/json" \
  -d '{"budget": 150000, "max_shift": 0.5}'

GET /api/response_curve?channel=tv

curl "https://this-deployment.vercel.app/api/response_curve?channel=tv&n_points=20"

POST /api/power

Geo-lift power analysis: minimum detectable effect and/or required test duration.

curl -X POST https://this-deployment.vercel.app/api/power \
  -H "Content-Type: application/json" \
  -d '{"tracking_error_std": 800, "baseline_weekly_revenue": 15000, "n_weeks": 8}'

GET /api/contribution?start=2021-01-01&end=2021-06-01

curl "https://this-deployment.vercel.app/api/contribution?start=2021-01-01&end=2021-06-01"
